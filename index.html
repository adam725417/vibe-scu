03 / BREAK IT DOWN

用 IPO 拆解機台溫度警報

情境：機台溫度過高時，系統要判斷狀態、顯示警示並模擬通知工程師。需求可以拆成三塊：

01 / INPUT

輸入

  • 每 2 秒模擬 20–120°C 的溫度
  • 工程師可設定警報閾值，預設 80°C
  • 提供「解除警報／確認」按鈕
02 / PROCESS

處理

  • 溫度低於閾值 → 正常
  • 溫度大於或等於閾值 → 過熱
  • 過熱時記錄模擬 Email 通知
  • 警報鎖定，直到恢復正常或手動確認
03 / OUTPUT

輸出

  • 監控面板顯示目前溫度
  • 綠色正常、紅色過熱
  • 最近 30 筆溫度趨勢
  • 明顯警報提示

06 / ACCEPTANCE CRITERIA
AI 寫完以後，如何驗收？
不要只問「程式能跑嗎？」。請它逐項測試以下六個具體情境，有問題就回報並要求修正。
✓
正常監控
閾值 100°C，輸入 85°C → 綠燈、無警報。
✓
觸發警報
閾值 80°C，輸入 81°C → 紅燈、Console 出現 Email 通知紀錄。
✓
即時解除
溫度 90°C，閾值從 80 改成 100°C → 不重整即可變綠燈。
!
無效輸入
輸入 ABC 或空值 → 顯示「請輸入有效的數字」。
!
API 斷線
5 秒無溫度資料 → 顯示灰色 Offline，不保留錯誤數據。
!
極端數值
輸入 999°C → 保留顯示並標註「異常數值」。
