放課後 Vibe Coding 部｜日系青春校園版
================================

快速使用：
1. 將 ZIP 檔完整解壓縮到任意資料夾。
2. 在 Chrome、Edge、Firefox 或 Safari 雙擊開啟 index.html。
3. 點選「開始動手」，即可調整需求、複製或下載 IPO_Sample.txt。
4. 頁面上的機台溫度模擬器可直接離線操作，不需伺服器。

檔案說明：
- index.html：完整教學內容與互動功能
- school.css：日系青春校園外觀
- IPO_Sample.txt：老師提供的原始完整 AI 開發提示詞

注意：網站字體使用線上 Google Fonts；離線時仍可操作，
只是會自動改用電腦內建字體。

這份下載包是靜態教學網站，不包含 Flask 機台監控後端；
Flask 專案是學生使用 IPO_Sample.txt 交由 AI 產生的實作成果。
